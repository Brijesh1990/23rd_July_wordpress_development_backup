# ShopHub Bootstrap Responsive Website

A responsive multi-page ShopHub ecommerce UI based on the supplied screenshot.

## Pages
- `index.html` — Home
- `products.html` — Product listing
- `product-details.html` — Product details
- `cart.html` — Shopping cart
- `checkout.html` — Checkout
- `order-success.html` — Order confirmation
- `faq.html` — FAQ accordion
- `account.html` — Login/register

## Technology
- Bootstrap 5.3.3 CDN
- Bootstrap Icons CDN
- Custom CSS in `css/style.css`
- Minimal JavaScript: only Bootstrap's bundled JS is used for responsive navbar and FAQ accordion.
- No custom JavaScript is required.

## Run
Open `index.html` directly in a browser, or serve the folder with any local web server.

## Notes
This is a front-end static demo. Product search/filter, authentication, cart persistence and checkout processing are intentionally non-dynamic. They can be connected later to PHP/Laravel/Node APIs.
